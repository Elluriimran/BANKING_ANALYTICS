Banking-Analytics
About

Comprehensive end-to-end Banking Analytics Project leveraging Excel, MySQL, Power BI, and Tableau. This repository covers the full data lifecycle—from extraction and cleaning with MySQL and Excel to interactive dashboard creation with Power BI and Tableau—providing actionable insights into banking operations.

Key Features

Data Processing: Imported, cleaned, and transformed banking datasets using SQL queries and Excel Power Query.

Interactive Dashboards: Designed responsive dashboards in Power BI and Tableau to visualize key metrics like credit vs. debit activity, loan trends, overdraft behavior, customer segments, and regional performance.

Analytic Insights: Utilized advanced SQL (e.g., GROUP BY, HAVING, JOIN, window functions) and DAX for deriving meaningful insights from raw data.

Visualization Styles: Included bar charts, pie charts, line charts, treemaps, and KPI indicators to present trends and highlight areas needing attention.
